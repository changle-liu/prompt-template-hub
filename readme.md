# 一键 Prompt

一个轻量的 Chrome Manifest V3 扩展，帮助你在日常 AI 对话中快速找到、生成并填入高质量的 prompt 模板。

内置约 100 个覆盖常见场景的模板，支持变量填写、实时预览、一键复制，以及在主流 AI 对话页面直接填入输入框。

## 功能亮点

### 模板浏览与检索

- **7 大分类**：内容创作、职场提效、知识学习、编程开发、日常对话、创意设计，以及「我的模板」
- **关键词搜索**：按标题、描述、标签快速筛选
- **最近使用**：自动记住上次选中的模板，方便连续使用

### Prompt 生成

- **变量填写**：根据模板字段生成完整 prompt，右侧实时预览
- **变量语法**：在模板正文中使用 `{{变量名}}` 或 `{{变量名|默认值}}`
- **草稿保留**：每个模板的填写内容和生成结果会本地保存，切换模板不丢失
- **灵活输出**：可复制生成后的 prompt，也可复制模板原文

### 自定义模板

- **新建 / 编辑 / 删除**：创建属于自己的 prompt 模板
- **添加到我的模板**：将内置模板复制一份后按需修改
- **变量配置**：支持文本、多行文本等字段类型，可设置必填与占位提示

### 一键填入

在支持的 AI 对话页面，点击「填入当前页面」即可将 prompt 写入当前输入框。插件会检测当前页面是否支持填入，并在顶部显示状态。

采用「站点专用选择器 + 通用输入框兜底」策略。若某页面无法识别输入框，复制功能仍可正常使用。

### 本地存储

所有个人数据保存在浏览器本地（`chrome.storage.local`），不上传服务器：

- 我的模板
- 最近使用的模板
- 各模板的填写草稿与生成结果

## 安装

### 从源码加载（开发者模式）

1. 克隆或下载本仓库
2. 打开 Chrome，访问 `chrome://extensions/`
3. 开启右上角「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择本项目的根目录（包含 `manifest.json` 的文件夹）

安装完成后，浏览器工具栏会出现扩展图标。

## 使用指南

1. 点击工具栏中的 **一键 Prompt** 图标，打开弹窗
2. 通过分类标签或搜索框找到目标模板
3. 点击左侧模板卡片，在右侧填写变量
4. 预览区会实时显示生成的 prompt，也可手动微调
5. 选择以下任一方式使用：
   - **复制 Prompt** — 粘贴到任意 AI 工具
   - **填入当前页面** — 在已适配的 AI 对话页直接写入输入框
   - **复制模板原文** — 获取未替换变量的原始模板

### 管理自定义模板

1. 点击「新建模板」创建空白模板，或从内置库点击「添加到我的模板」
2. 在编辑器中填写标题、分类、标签、变量和正文
3. 点击「保存模板」；如需修改，选中后点击「编辑」
4. 在「我的模板」分类下可查看、编辑或删除自定义模板

### 变量写法示例

模板正文：

```text
请用{{语气|专业、简洁}}的语气，帮我润色下面这段文字：

{{原文}}
```

填写「语气」和「原文」后，变量会被替换为实际内容；未填写的变量会使用默认值。

## 项目结构

```text
prompt-template-hub/
├── manifest.json          # 扩展配置（MV3）
├── background.js          # Service Worker，初始化本地存储
├── content.js             # 内容脚本，负责页面填入
├── popup.html             # 弹窗界面
├── popup.css              # 弹窗样式
├── popup.js               # 弹窗逻辑
├── icon.png               # 扩展图标
├── _locales/
│   └── zh_CN/
│       └── messages.json  # 扩展名称与描述（i18n）
├── data/
│   └── templates.js       # 内置分类与模板数据
└── readme.md
```

## 技术说明

- **Manifest V3**：使用 Service Worker 作为 background，content script 注入目标页面
- **权限**：`activeTab`、`storage`、`scripting`，以及对上述 AI 站点的 `host_permissions`
- **无后端**：纯前端扩展，模板数据打包在 `data/templates.js` 中
- **填入机制**：content script 根据当前域名匹配选择器，优先定位 AI 输入框；支持 `textarea`、`contenteditable` 等元素

## 常见问题

**填入当前页面没有反应？**

AI 产品会频繁调整页面结构，可能导致填入失效。请改用「复制 Prompt」手动粘贴。欢迎在 Issue 中反馈无法填入的页面。

**自定义模板会丢失吗？**

模板保存在浏览器本地存储中。清除扩展数据或卸载扩展会导致丢失，目前不支持导出/导入。

**如何新增内置模板？**

编辑 `data/templates.js`，在 `PROMPT_TEMPLATES` 数组中按现有格式添加条目，重新加载扩展即可。
